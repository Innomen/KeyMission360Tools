# Privacy

KeyMission360 Tools is local software. It has no accounts, cloud service, telemetry, advertising,
or network upload. Camera communication uses USB through gphoto2. Media is written only to the
folder you select.

The app does not log filenames, thumbnails, media, camera identifiers, Wi-Fi credentials, or
copyright fields. Command-line output may show filenames when you explicitly request a file list.
No application can protect data from another process running as the same operating-system user.
